Dockerfile php-fpm, сверху вниз

1. FROM php:8.4-fpm — взять готовый PHP 8.4. Нужно, с этого начинается образ.

2. WORKDIR "/application" — сделать /application текущей папкой внутри образа. Для сайта не обязательно: папку и так даёт compose.

3. apt-get update — обновить список пакетов, чтобы следующие строчки вообще нашлись. Нужно.

4. curl — программа, которой ниже скачивается Composer. Нужно.

5. zip — программа для архивов. Нужно, Composer ими пользуется.

6. unzip — распаковка архивов. Нужно, по той же причине.

7. nano — текстовый редактор внутри контейнера. Не нужно.

8. libzip-dev — запчасть, чтобы ниже собралось расширение PHP zip. Нужно.

9. libicu-dev — запчасть для расширения intl. Нужно.

10. libpng-dev — запчасть для картинок, расширения gd. Не нужно, пока сайт не обрабатывает картинки.

11. libjpeg62-turbo-dev — то же, jpeg для gd. Не нужно, пока нет картинок.

12. libfreetype6-dev — то же, шрифты для gd. Не нужно, пока нет картинок.

13. docker-php-ext-configure intl — подготовить сборку intl. Нужно.

14. docker-php-ext-install intl — включить intl. Даты, деньги, переводы. Laravel без него ругается. Нужно.

15. zip в той же команде — расширение PHP для архивов. Нужно.

16. pdo_mysql в той же команде — связь PHP с MySQL. Нужно, без него Laravel не подключится к базе.

17. docker-php-ext-configure gd ... — подготовить gd с jpeg и шрифтами. Не нужно, пока нет картинок.

18. docker-php-ext-install gd — включить обработку картинок. Не нужно, пока нет картинок.

19. curl ... composer — скачать Composer и положить команду composer в контейнер. Нужно, им ставятся пакеты Laravel.

20. apt-get clean && rm -rf /var/lib/apt/lists/* — стереть кэш установщика. На работу сайта не влияет, образ просто меньше. Можно убрать.
